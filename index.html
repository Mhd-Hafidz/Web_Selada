Cara kerja

ESP32 sensorWiFi, tiap 1 detik →Firebasedibaca →Dashboard
ESP32-CAMHTTP, jaringan yang sama →Dashboard

Data sensor lewat internet lewat Firebase. Video kamera tidak lewat Firebase, jadi perangkat yang membuka dashboard harus satu jaringan dengan kamera.

Langkah pemasangan

  1. Nyalakan ESP32 sensor. Bila belum punya WiFi tersimpan, LCD menampilkan "WiFi: esp selada" dan hotspot bernama esp selada keriting aktif.
  2. Hubungkan HP atau laptop ke hotspot itu, buka 192.168.4.1, pilih WiFi rumah atau hotspot, lalu simpan.
  3. Cek LCD. Setelah tersambung, LCD menampilkan alamat IP dan data mulai terkirim ke Firebase tiap 1 detik.
  4. Nyalakan ESP32-CAM. Sambungkan ke WiFi ESP32-CAM-SELADA, buka 192.168.4.1, isi WiFi yang sama, dan catat IP yang muncul.
  5. Buka halaman Kamera di dashboard ini, masukkan IP tadi, lalu klik Hubungkan.

Pemecahan masalah

Data sensor tidak muncul

Pastikan ESP32 sensor tersambung WiFi (LCD menampilkan IP), URL di Pengaturan sama dengan URL di program, dan aturan baca Firebase mengizinkan akses. Gunakan "Uji koneksi" di Pengaturan.

Status "Perangkat berhenti mengirim data"

Tidak ada data baru selama batas waktu di aturan Perangkat offline. Cek daya dan WiFi ESP32 sensor.

Suhu atau udara tidak berubah

Program hanya memperbarui nilai bila DHT22 berhasil dibaca. Jika sensor gagal, nilai lama tetap dikirim. Cek kabel DHT22 di pin 13.

Pompa terus menyala atau tidak pernah menyala

Kalibrasi sensor tanah memakai nilai kering 4000 dan basah 2800. Sesuaikan dengan sensor Anda. Relay bersifat aktif LOW, jadi LOW berarti pompa menyala.

Video kamera tidak tampil

Kamera hanya melayani satu penonton. Tutup tab portal kamera, pastikan satu jaringan, dan buka dashboard lewat http bila ada pesan konten tidak aman.
